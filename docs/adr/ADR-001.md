# ADR-001: Hybrid Rust + TypeScript

Status: accepted for beta candidate.

Context: preserve reusable native semantics while enforcing narrow remote boundaries.

Decision: Keep graph semantics native and security/transport policy in TypeScript; do not duplicate ranking/traversal algorithms.

Consequence: extra deployment boundaries and explicit configuration; simpler transport adapters and independently testable policies. Revisit through an ADR and regression tests, not an implicit fallback.
