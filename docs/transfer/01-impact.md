# Feature 1: impact and trace

API: `impact(graph, options)`, `trace(graph, options)`, `scopeGraph(graph, scope)`.
Types/schemas: `GraphSnapshot`, `GraphNode`, `GraphEdge`, `GraphEvidence`,
`graphSnapshotSchema`, `impactOptionsSchema`, `traceOptionsSchema`.
Reports advertise `analysisContract: 2`; the portable MCP advertises `portable-2`.

```ts
import { impact } from 'system-graph-remote/platform';
const result = impact(snapshot.graph, {
  target: 'service-b', asOf: '2026-11-16T00:00:00Z',
  direction: 'upstream', maxDepth: 8, limit: 20, offset: 0,
});
```

Input is a normalized versioned graph. Edges point from consumer to dependency;
`propagatesImpact` explicitly selects dependency relationships for traversal.
Evidence carries repository/environment, extractor, source, confidence and
observation time. Provenance and paths survive MCP projection subject to the
existing redaction policy. Every candidate has its shortest discovered path,
direct/indirect classification, quality and a possible-impact semantic label.
Service aggregation is separate from node candidates.

Services are repository-owned logical identities with environment/deployment
bindings. `logicalService` is distinct from `shared`; only permitted bindings and
their evidence survive scoping. Aggregation includes permitted environments and
deployment IDs. A source's environment or first deployment cannot fix the logical
service to that environment. Unknown environments still need explicit permission.

Coverage issues retain their repository and optional artifact/digest/deployment
applicability. Environment-independent applicability is explicit; environment null
alone still denotes unknown. Use `coverageIssues` for these typed facts and
`coverageGaps` for the human-readable summary.

Upstream finds consumers; downstream finds dependencies; both is explicit.
Cycles are visited once. `totalIsExact` is false on exploration truncation;
`total` then describes discovered candidates. `nextOffset` pages those candidates
and does not resume an unfinished search. Increase bounds and rerun against the
same snapshot to expand the explored set. Keep snapshot, time, scope, target,
direction and bounds fixed between pages. Inventory edges use separate paging.

Risk is a bounded qualitative heuristic, using explicit change compatibility and
supplied criticality plus evidence freshness/completeness. Missing context or
uncertain paths gives UNKNOWN with reasons. A missing path/candidate set never
proves safety. Trace quality distinguishes confirmed, inferred, ambiguous and stale.

The pure API trusts its already authorized graph. Call `scopeGraph` first in a
custom access-controlled adapter, or use `PlatformQueryService`. Shared nodes are
not an authorization bypass; only allowed anchors and allowed evidence can expose
them. The store/auth/data-provider connections belong to the integrating application.

Tests: `node --test dist/tests/platform-graph.test.js`; fixtures are generated by
the test, including the exact 60-candidate/20-row pagination case. MCP:
`graph_impact`, `graph_trace`, `graph_inventory`, `graph_explain` in `--platform`
mode. The cross-source integration test is `platform-mcp.test.ts`.
