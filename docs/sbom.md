# SBOM and native/runtime evidence

Application SBOM: **380 unique components** from 383 resolved npm/Cargo package instances (281 Cargo / 102 npm). The corresponding license inventory has no missing declared license field; that does not clear redistribution. Registry sources, optional/platform/build dependencies and local crates are distinguished by the detailed inventory and native evidence.

Container SBOM: **411 components**, including actual Node bundled version entries, Rust static SQLite and three Debian-owned shared-library packages. Only three npm packages survive production prune; their actual installed manifest sets required scope. Other resolved app inventory is conservative optional coverage, not proof of binary reachability. Node bundled version fields are not separately upgradable OS packages. Dependency-edge completeness is not asserted.

The container inventory reads a build-time ELF/file-owner manifest from the actual image, rather than pretending no packages exist because scratch lacks dpkg. It records each copied shared object and binary hash, undefined imports, Node process.versions, exact native SQLite header version, native link-map hash and corresponding-source archive hashes. No dynamic OpenSSL/libsqlite dependency is claimed for the engine; Node includes its own native bundle.

Both CycloneDX 1.5 documents pass the official schema and unique-reference check. This establishes format, not security, legal clearance or complete static call-graph attribution. npm/Cargo OSV package-version scan and Debian source-package/version scan are separate. The 84-record review retains raw severity, fixes, runtime presence, conditions and expiring contextual decisions. New/stale/mismatched evidence and unresolved exposure fail closed. Official Node core advisory ranges (204 records) were cross-checked for 24.22.2 with zero matches, alongside verified official Node source/binary identity. This supplements npm/Cargo/OS scans; OS package removal is not a blanket exemption and no database guarantees completeness.
