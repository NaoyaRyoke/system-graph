## Unresolved redistribution issues

- **pratt 0.4.0** declares MIT, but neither its published crate nor exact source revision `4a00d5eaf44aabc0856ae4e1d05fcd8eab646a94` contains a license file. Original manifest/README and an explicit unresolved declaration are retained. No copyright holder or license grant was invented. Obtain authoritative clarification/notice or replace/remove it after a separate compatibility review. Until then publication fails the distribution gate.
- Per-file modification marking is complete for all 71 changed/added files; original notices retained. The legacy schema identity is pinned by an additional compatibility test. This closes the inherited-notice issue, not the separate pratt issue.
- Supplemental winapi import-library packages have no crate VCS record; upstream project 0.3.9 license texts are retained with that limitation. They are Windows build inventory, not Linux runtime payload. Verify exact release provenance before distributing platform binaries separately.

## Corresponding source and replacement

The runtime includes exact `.dsc`, original tar and Debian patch archives for glibc/GCC under `/licenses/corresponding-source`, with SHA-256 in runtime `native-components.json` and source `licenses/corresponding-source.json`. This is actual accompanying source, not an unsupported promise to host it later. Use `docker create` and `docker cp` on the candidate image to extract the directory without running the service; remove only that temporary container. Keep all three parts for each source package. The dsc identifies build inputs; apply Debian patches with `dpkg-source -x` in a separate build environment and consult its Debian build rules. Build tools are deliberately absent from runtime.

For LGPL shared-library replacement/relinking, rebuild the scratch rootfs with compatible rebuilt shared objects at the recorded manifest paths; the Node/engine executables link dynamically to libc/libstdc++/libgcc. No signature lock prohibits replacement, and source/build scripts are included. This is not a warranty that an arbitrary ABI-incompatible replacement works. Node bundled native components retain the complete upstream license; changing them requires rebuilding Node from its matching source/version.

The source ZIP contains project/vendored source and attribution texts, not third-party ELF binaries or the 118 MB of Debian source archives. The runtime carries those archives itself. If distributing extracted binaries separately, attach the same notices and corresponding-source payload and rerun the platform audit. No registry/source artifact is uploaded by this work.
