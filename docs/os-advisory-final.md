# Final OS/dependency advisory review

This is a contextual assessment of the exact Linux AMD64 artifact, not a reduction of scanner severity. Raw current scan remains Critical 1 / High 8 / Medium 13 / Low 2 / unknown 3. App OSV (383 package queries) and independent npm audit both report zero; official Node core advisory data checks 204 version ranges with zero matches for 24.22.2. Scans are repeated against the final image.

## Exact-artifact evidence

- Official Node 24.22.2 source archive SHA-256 verified against release SHASUMS256. Its source archive hash is 8fe2ec1723bb9f8d0b683907c82708debbeda64af21cb2aa214c4241eed0a061. Official Linux x64 bin/node matches the copied ELF byte-for-byte (904a6d3484241d466989f9df9ba3aab822b1496191bdb28230eb491a55c32a52). Full symbols and compiler .comment are recorded, not just dynamic imports.
- PBDS / GNU parallel-mode search and wide-stream bitset extraction are not used by the matching runtime source or symbols. These are caller-instantiated header defects, not automatically every program linking libstdc++.
- V8 vector<bool> runtime uses were traced. Wasm tags are checked by consume_count against kV8MaxWasmTags = 1,000,000; the affected constructor requires size/range near 64-bit SIZE_MAX. Other use is debug-only push/pop bookkeeping. MCP accepts data, not JavaScript/Wasm/inspector/module execution; readonly graph projections are bounded. Presence of vector<bool> is acknowledged.
- Exact runtime libstdc++ hash matches the disassembled library. Array aligned-new delegates to scalar aligned-new, which calls posix_memalign. An independently written allocation check rejected all 24 enormous requests in a nonroot/read-only/network-none 64 MiB container; no payload memory was accessed. Upstream fix explicitly excludes this POSIX path.
- glibc upstream REST bug 22850/comment was read successfully; maintainer comment 3 distinguishes post-attack mitigation from a security defect. No libc fix/removal or universal memory-safety guarantee is invented. See https://sourceware.org/bugzilla/rest/bug/22850/comment .

## Cross-check and expiry

OSV raw source-package matching disagrees with artifact applicability for header-only, non-POSIX and upstream-disputed records. Both outputs are retained. npm audit independently agrees with npm OSV on zero findings. Debian tracker/upstream fixes, Node official source and Node security data complement scanners; no claim of running Trivy/Grype is made.

All decisions expire on the recorded review date or immediately on relevant image/toolchain/Node/dependency/entrypoint/API/graph-limit/environment changes. New advisory IDs, mismatched manifest hashes and missing reviews fail closed. Native ARM64, Wine and arbitrary native/plugin/JS execution are not covered.
