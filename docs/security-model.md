# Security model

The resource server verifies an access token on every request. `AuthProvider` is replaceable; `JwtAuth` + injected `KeySource` performs RS256 verification with a strict header allowlist. Configured JWKS is public key material, not fetched from `jku`, `x5u` or a client URL. Unknown kid fails closed. Key replacement is atomic; a rejected replacement preserves old keys. Operators rotate/reload keys explicitly; provider-side revocation/introspection is not built in. Maximum accepted remaining lifetime is ten minutes, with no permissive clock-skew fallback.

Issuer, audience, subject, exp, optional nbf/iat, `graph:read` and explicit issuer+subject mapping are mandatory. If a signed tenant claim exists it must match that mapping. Client tenant headers/arguments cannot assign identity. No ID token is accepted as an access token. No write/admin scope is returned. Authorization intersects principal permission with workspace environment/repository scope before spawning/dispatching. Unknown/denied workspaces have the same denial; unknown/foreign IDs have the same not_found response.

Trusted reverse-proxy model: the edge authenticates the caller and forwards a resource-bound short-lived signed assertion to this same JWT verifier. Plain `X-User`/`X-Tenant` trust is unsupported. Direct access to backend networks must be prevented by the operator. Explicit static bearer hashes are dev/self-host-loopback only; mock fixture runtime is not selected by the public executable. No default credentials are shipped.

A public runtime admits exactly one workspace, one DB and explicit permissions. Separate containers/filesystem mounts supply the OS boundary; the test gateway reaches isolated per-workspace networks. No Docker socket, host tree or another tenant graph is mounted. All processes use UID 10001, without capabilities or writable root. This is stronger than shared-UID workers, but a compromised gateway/host remains a trusted boundary. Kubernetes/namespace/VM isolation is a future option, not implemented.

`registeredFile` rejects relative paths, dot-dot, symlink/junction components and canonical escape. Realpath/inode checks reject aliasing. Files must be provisioned in immutable read-only mounts; the application alone cannot eliminate administrator replacement/TOCTOU races. No repository filesystem is read at query runtime. Arbitrary nested bind mounts created by a hostile host are outside the boundary.

Provenance response policy permits only selected facts, workspace-relative source names, constructed property pointers and bounded extractor/origin/evidence metadata. Absolute paths, home-directory paths, UNC paths, URLs and credential-pattern text are redacted; freeform bodies, raw stable keys, arbitrary annotations and environment values are not forwarded. This is not universal DLP: operators must not ingest secrets. Responses are untrusted evidence, never tool instructions.

HTTP ingress enforces exact Host/Origin, no CORS, no forwarded-header identity, bounded auth waits/connections/body/response and cancellation. Tokens live in a request only and are not echoed in audit/metrics/errors. Audit is currently bounded RAM metadata; durable audit, multi-instance quotas and revocation freshness need separate infrastructure before production.
